# Changelog
### Update Notes
This update adds new mobs that were based on mobs in [EmberRoot Zoo](https://www.curseforge.com/minecraft/mc-mods/emberroot-zoo), see [here](https://github.com/Lothrazar/ERZ/blob/trunk/1.12/LICENSE.txt) for licensing.
## 1.2.0
### Added
- Added the Earthen Golem, these golems will chase you down while also performing a ranged attack at the same time. There are many different variants of stone to look out for, you might be able to obtain rare gems as drops like diamonds!
- Added Fairies, glowing flying passive mobs that spawn in magical and swamp biomes.
- Added the Restless Hero, these undead will spawn at night and fight hostiles, they are best left alone.
- Added Spritelings, glowing flying neutral mobs that spawn in magical and swamp biomes, watch out for their dash attack!
- Added Fae Dust, dropped by Fairies and currently only used to create Fae Light.
- Added Sprite Essence, dropped by Spritelings, currently only used to create Leaf-Bladed tools and a Fae Light variant.
- Added Leaf-Bladed Axe and Leaf-Bladed Sword, these deal +50% damage to animals and fae creatures.
- Added Fae Light and variants (Confusing, Sprite, and Withering), these are placeable glowing particle emitters!
- Added a new particle system that will be utilized throughout the mod.
- Added Embers integration, Earthen Golems will drop items from Embers' Ancient Golems when enabled.
### Changed
- Certain mobs are now considered "Fae" (Fairy, Spriteling, and Witch's Cat).
### Fixed
- Fixed Fallen Steed changing its texture to a vanilla horse during certain instances.
- Fixed Fallen Steed not being considered as undead.

## 1.1.0
### Update Notes
This update ports all the mobs from [Obly's Sheepers Creepers](https://www.minecraftforum.net/forums/mapping-and-modding-java-edition/minecraft-mods/1283042-1-5-0-forge-smp-ssp-oblys-sheepers-creepers-v1-2)! Courtesy of Oblyvian for making the original mod.
### Added
- Added the Blaze Cow, it can be farmed for blaze rods and will fill buckets with lava. Melee attacks against it will burn you!
- Added the Ender Chicken, another source for farming Ender Fragments.
- Added the Sheeper, a mix of a Creeper and Sheep. It can be sheared for Gunpowder, but will explode if panicked.
### Changed
- Confusing Dust can now be used to breed Ender Chickens and Sheepers.
- Withering Dust can now be used to breed Blaze Cows.
### Fixed
- Fixed Khndrel Keghts and Void Cubes still attempting to spawn on Peaceful difficulty.
